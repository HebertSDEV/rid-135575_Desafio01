Blog Responsivo - DNC

## Descrição
Projeto de blog com layout responsivo, desenvolvido como parte do curso da DNC. O objetivo foi replicar fielmente o protótipo e garantir adaptação para dispositivos móveis.

## Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox, Media Queries)
- Visual Studio Code
- Figma
- Git e GitHub

## Funcionalidades
- Layout principal com posts populares, recentes e categorias
- Responsividade para telas pequenas
- Organização modular de estilos

## Desafios e Soluções
### Dificuldades
- Alinhamento de seções com Flexbox
- Comportamento inesperado ao aplicar `flex-wrap`
- Ajustes finos em media queries

### Soluções
- Uso de `box-sizing: border-box` para controle de dimensões
- Separação de estilos por classes específicas
- Testes em diferentes resoluções
